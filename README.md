# Spectra GrowthDesk

**Spectra GrowthDesk** is a premium AI-powered social media growth platform for agencies and brands. It combines AI content creation, client approvals, scheduling, publishing, analytics, reporting, and full admin operations in one branded workspace.

## Tagline

**Grow louder. Grow smarter.**

## Demo accounts

- Client: `client@example.com` / `client123`
- Admin: `admin@spectragrowthdesk.com` / `admin123`

## Pages

- `index.html` — Public marketing website
- `login.html` — Client and admin sign-in
- `client.html` — Client Portal
- `admin.html` — Admin Control Center
- `styles.css` — Spectra design system
- `app.js` — Prototype logic and local data persistence
- `docs/product-blueprint.md` — Product, pricing, data, and integration blueprint
